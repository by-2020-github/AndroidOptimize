# 小米系统精简优化手册

生成时间：2026-08-25 22:45:32

这份手册基于当前设备 ADB 扫描结果生成，用来区分“已经精简”的组件，以及“仍然保留、可继续处理”的目标组件。

## 使用原则

- 优先处理广告、推荐、预装内容和游戏分发类组件。
- 涉及安全、互联互通、辅助功能的组件要先确认自己确实不用，再动。
- 统一使用 ADB 对用户 0 卸载，必要时可通过 install-existing 恢复。

## 常用命令

```powershell
adb shell pm uninstall -k --user 0 <包名>
adb shell cmd package install-existing --user 0 <包名>
adb shell pm list packages --user 0 | Select-String '<关键字>'
```

## 建议执行顺序

1. 先处理“广告与跟踪”“推荐与内容流”“预装应用”这三类。

## 恢复说明

如果某个组件精简后出现闪退、投屏失效、文件分享异常或系统设置缺项，优先执行恢复命令：

```powershell
adb shell cmd package install-existing --user 0 <包名>
```

恢复后建议重启一次手机，再验证对应功能。
